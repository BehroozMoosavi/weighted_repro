displayed as equally spaced categories. This is a sensitivity study, not
the tuning rule used in the main experiments, which prespecify

reduction for the $\sigma$ target is smaller. Recorded coverage exceeds
the Monte-Carlo-adjusted screening floor $0.9365$ throughout; this
screening criterion is not a coverage guarantee. The simpler search and
coarser endpoint tolerance differ from those used for
Table~\ref{tab:exp1-main}, so absolute widths should be compared within
